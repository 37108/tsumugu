# What is Tsumugu?

This guide is also available in [日本語](/ja).

Tsumugu turns a directory of Markdown, MDX, and HTML files into a documentation
site. It derives routes and navigation from the files, so there is no
configuration file to maintain.

This site runs on Tsumugu itself. From a checkout, `pnpm docs` serves the same
pipeline that the packages ship.

Tsumugu is experimental and pre-alpha. Its APIs may change between releases.
