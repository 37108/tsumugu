# 紡ぐとは

このガイドは [English](/en) でも読めます。

Tsumugu は、Markdown、MDX、HTML の入ったディレクトリを、そのまま
ドキュメントサイトとして配信するツールです。ルーティングとナビゲーションは
ファイル構成から作るため、設定ファイルはありません。

このサイト自体も Tsumugu で配信しています。チェックアウトした状態で
`pnpm docs` を実行すると、パッケージが出荷しているものと同じパイプラインが
立ち上がります。

Tsumugu は実験段階（pre-alpha）です。API はリリース間で変わることがあります。

## ガイドの外にあるもの

設計資料は、このガイドの外に英語で置いてあります。[Designs](/designs) は
アーキテクチャとその制約、[Decisions](/decisions) は採択済みの ADR、
