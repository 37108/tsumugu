# オプション

[English](/en/options) 版もあります。

設定ファイルはなく、環境変数もありません
（[ADR 5](/decisions/0005-no-configuration-file)）。Tsumugu に指示できることは
このページに全部あります。コマンドが 2 つ、そのオプション、そして文書ごとの
front matter の 4 つのキーです。

## コマンド

```bash
npx tsumugu dev [ディレクトリ] [オプション]     # 書きながら localhost で配信
npx tsumugu build [ディレクトリ] [オプション]   # 静的サイトをディレクトリに書き出す
npx tsumugu --version                          # バージョンを表示
npx tsumugu --help                             # 同じ一覧を短く表示
```

知らないオプションは推測せずエラーにし、そのコマンドが受け付けるオプションを
メッセージに並べます。`--locales` と `--lang` はそれぞれ 1 回だけ指定できます。

## どのディレクトリが配信されるか

ディレクトリは位置引数です（`tsumugu dev docs`）。`--root docs` は同じことを
フラグで書いた形です。どちらもない場合は、次の順で探します。

1. `./docs` があればそれ。多くのリポジトリが既に従っている慣例です。
2. カレントディレクトリ。ただし index 文書（`index.md`、`index.markdown`、
   `index.html`、`index.htm`）がある場合だけ。

どちらもなければ、コマンドは停止して次に何をすればよいかを伝えます。index の
ないカレントディレクトリは、ドキュメントのルートよりプロジェクトのルートで
ある可能性がずっと高く、配信すればリポジトリ中の Markdown を巻き込みます。

## `dev` のオプション

| オプション              | 何が変わるか                                                   | 既定値      |
| ----------------------- | -------------------------------------------------------------- | ----------- |
| `--root <ディレクトリ>` | 配信するディレクトリ。位置引数と同じ。                         | 自動で決定  |
| `--host <ホスト>`       | バインドするインターフェース。既定はループバックのみ。         | `127.0.0.1` |
| `--port <ポート>`       | バインドするポート。`0` は空きポートで、URL を表示。           | `0`         |
| `--locales <タグ>`      | 別スコープとして配信するロケールディレクトリ（カンマ区切り）。 | なし        |
| `--lang <タグ>`         | ロケールディレクトリ外の文書の HTML 言語。                     | `en`        |
| `--trust`               | ルートの中身が自分のものだと宣言し、コードとして動かす。       | 無効        |

watch にフラグはありません。`dev` は常にルートを監視し、変更分だけを
再ビルドして、開いているページを再読み込みします。再ビルドが失敗しても、
最後に成功した版を配信し続けます。ライブリロードにもフラグはありません。
Tsumugu がページに足す唯一のスクリプトで、静的ビルドには入りません
（[ADR 3](/decisions/0003-live-reload-script-policy)）。

## `build` のオプション

| オプション              | 何が変わるか                                                        | 既定値     |
| ----------------------- | ------------------------------------------------------------------- | ---------- |
| `--root <ディレクトリ>` | ビルドするディレクトリ。位置引数と同じ。                            | 自動で決定 |
| `--out <ディレクトリ>`  | サイトの書き出し先。                                                | `./dist`   |
| `--origin <URL>`        | 公開先のオリジン。`sitemap.xml` が使います。                        | なし       |
| `--base <パス>`         | サイトが配信されるパスの接頭辞。GitHub Pages なら `/リポジトリ名`。 | `/`        |
| `--locales <タグ>`      | 別スコープとしてビルドするロケールディレクトリ（カンマ区切り）。    | なし       |
| `--lang <タグ>`         | ロケールディレクトリ外の文書の HTML 言語。                          | `en`       |
| `--clean`               | Tsumugu が書いたものでない出力ディレクトリも削除する。              | 無効       |
| `--trust`               | ルートの中身が自分のものだと宣言し、コードとして動かす。            | 無効       |

`--clean` がなければ、Tsumugu は自分の出力だと分かるディレクトリ以外を消さない
ので、`--out` を間違えても失うものはありません。`--base` は先頭のスラッシュ 1 つ、
末尾なしに正規化されるため、`/my-repo`、`my-repo/`、`//my-repo` はすべて同じ
意味になります。

## `--locales` と `--lang`

`--locales ja,en-US` はルートの直下のディレクトリを指定し、それぞれを独立した
スコープにします。`/ja` と `/en-US` はそれぞれのナビゲーション、検索、
`documents.json`、`llms.txt` を持ち、互いのページは出てきません。ルートに
残ったものは共通のままです。ルートの `sitemap.xml` はサイト全体を含みます。

値は Unicode のロケール識別子で、正規化されるため `en-us` は `en-US` という
ディレクトリを選びます。指定したディレクトリがない場合や、2 つの値が正規化後に
同じロケールになる場合は、配信もビルドも始める前に停止します。タイプミスが
「中身のない節」として黙って通ることはありません。

`--lang` が設定するのは共通スコープの HTML 言語だけです。ロケールのスコープは
`--lang` が何であれ自分のロケールを使います。理由は
[ADR 8](/decisions/0008-explicit-locale-scopes) にあり、ディレクトリの形は
[使い方](/ja/how-to-use#ロケールを分ける)にあります。

## `--trust`

既定で無効で、推測されることはありません。付けない限り、ドキュメントは内容
として扱われます。HTML の `<script>` は取り除かれ、MDX の式やコンポーネントは
ソースとして表示されます。付けると「このディレクトリは自分のものだ」という宣言
になり、マークアップは書かれたまま出力され、スクリプトは動き（インラインは
ハッシュで、ファイルは `'self'` で許可され、外部オリジンは決して許可されません）、
`.mdx` はページを組み立てる間に実行されます。

自分で書いたものでない内容には付けないでください。理由は両方とも記録されて
います。内容を実行しない理由は
[ADR 6](/decisions/0006-mdx-without-execution)、フラグ 1 つで済ませている理由は
[ADR 7](/decisions/0007-operator-opt-in-trust) です。

## 文書ごとの front matter

文書に対する設定は front matter がすべてで、キーは 4 つです。

```yaml
---
title: セットアップ # 省略時は最初の見出し、次にファイル名
description: 一文の説明。 # 一覧・検索・llms.txt に表示
order: 2 # 兄弟間での並び順。順序のないページはタイトル順で後ろに並ぶ
hidden: true # どこにも載せないが、URL では配信される
---
```

| キー          | 型     | 省略したとき                                  |
| ------------- | ------ | --------------------------------------------- |
| `title`       | 文字列 | 最初のレベル 1 見出し、なければファイル名。   |
| `description` | 文字列 | 一覧・検索結果・`llms.txt` に説明が付かない。 |
| `order`       | 数値   | 順序付きの兄弟の後ろに、タイトル順で並ぶ。    |
| `hidden`      | 真偽値 | 載るべき場所すべてに載る。                    |

`hidden: true` はナビゲーション、検索、`llms.txt`、`sitemap.xml` からページを
外しますが、URL では配信されます。非公開ではなく、一覧に出ないだけです。
`documents.json` だけは意図的に例外で、`hidden: true` を付けたままページを
含めます。プロジェクトの中身を尋ねる道具には事実を渡し、どう扱うかはその道具に
決めさせるためです。

知らないキーは拒否せずそのまま残します。Tsumugu にまだ機能がないことを著者が
書いている、という扱いです。`hiden` のような近いタイプミスには「もしかして
`hidden`?」という警告が出ます。`order: nope` のような型違いも警告どまりです。
ページは読める状態のままで、配信を拒否すれば著者のタイプミスで読者が損をします。

## 終了コード

| コード | 意味                                                   |
| ------ | ------------------------------------------------------ |
| `0`    | 完了。`--help` と `--version` もここで終わります。     |
| `1`    | コマンドラインを理解できなかった。コマンドを直します。 |
| `2`    | コマンドは正しかったが、サーバーを起動できなかった。   |

スクリプトが分岐できるように固定してあります。`1` は再実行しても成功しません
が、`2` は成功することがあります。
