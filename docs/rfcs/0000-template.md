# RFC N: Title

- **Status:** Draft | Accepted | Rejected
- **Date:** YYYY-MM-DD
- **Related:** issues, ADRs, documents

## Problem

What cannot be done today, who needs it, and what they do instead. If nobody
does anything instead, say why the need is real anyway.

## Proposal

The design, concretely: names, boundaries, package placement, and what becomes
public. State what the proposal deliberately does not cover.

## Fit

Which principles in `docs/designs/principles.md` this leans on, and which it strains.
A proposal that strains none is usually restating the status quo.

## Alternatives

The nearest designs not proposed, each with the reason it lost.

## Evidence

What has to be true for this to be accepted, such as usage, a prototype, or a
benchmark, and how much of it exists now.
