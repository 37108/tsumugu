# Configuration

There is no configuration file. What would be configuration elsewhere is
convention here.

## Options

| What               | How                                           |
| ------------------ | --------------------------------------------- |
| documentation root | the directory you pass to `tsumugu dev`       |
| a page's title     | the first heading, or `title` in front matter |
| ordering           | `order` in front matter                       |
| hiding a page      | `hidden: true` in front matter                |

> A page that is hidden keeps its route. It is unlisted, not unreachable.
