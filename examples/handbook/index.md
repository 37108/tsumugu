# Team handbook

An example of what a real documentation directory looks like: sections, a page
written in HTML, front matter that sets titles and ordering, an image, and one
page deliberately kept out of the navigation.

## Where to start

- [Getting started](/guide/getting-started) sets the project up.
- [Configuration](/guide/configuration) covers the options.
- [The API reference](/reference/api) is generated by hand, like everything else here.

## How this directory is organised

Routes follow the file system. `guide/getting-started.md` is served at
`/guide/getting-started`, and `guide/index.md` is the section's own page at
`/guide`.
